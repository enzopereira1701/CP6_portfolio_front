NovaCore

Atividade de revisão

Abrir site

Landing page de uma empresa fictícia de soluções digitais. A atividade era revisar tudo o que vimos antes dos frameworks, então cada parte foi escrita à mão, só com HTML e um arquivo de CSS.

O que tem no site

  • Menu com links que rolam até cada seção
  • Abertura com chamada e botão “Quero conhecer”
  • Seis serviços em cards: web, mobile, automação, integrações, dados e UX
  • Seção sobre a empresa e três depoimentos de clientes
  • Formulário de contato e rodapé com links, telefone e endereço

O que pratiquei

  • Estrutura semântica com header, nav, main, section e footer
  • Flexbox para o menu, os cards e o rodapé
  • Classes reutilizáveis para títulos, textos e botões
  • Efeitos de hover e transições nos botões
  • Media query para adaptar o layout a telas de até 700px

Tecnologias: HTML, CSS, Flexbox e fonte Poppins

Grão Nobre

Atividade de Bootstrap

Abrir site

Site de uma torrefação fictícia que vende cafés especiais por assinatura. O desafio era reproduzir um layout usando apenas os componentes e as classes do Bootstrap 5, sem nenhuma linha de CSS ou JavaScript próprio.

O que tem no site

  • Navbar escura que vira menu “hambúrguer” no celular
  • Botão “Comprar agora” que abre um modal para escolher o pedido: kit de degustação, 1 ou 5 pacotes
  • Abertura com título, texto e foto do café
  • Carrossel de depoimentos com avaliação em estrelas
  • Perguntas frequentes que abrem e fecham em accordion

O que pratiquei

  • Grid de 12 colunas com row e col para dividir a página
  • Componentes prontos: navbar, modal, carousel e accordion
  • Classes utilitárias de espaçamento, cor e tipografia
  • Imagem com proporção fixa usando ratio e object-fit
  • JavaScript do Bootstrap para os componentes interativos

Tecnologias: HTML e Bootstrap 5.3

Fio & Prensa

Atividade de Tailwind

Abrir site

Site de um ateliê fictício de encadernação artesanal. O briefing trazia a paleta (verde profundo, off-white, vermelho e dourado) e as fontes Fraunces e Work Sans; todo o visual foi construído com classes utilitárias do Tailwind CSS 4.

O que tem no site

  • Menu com botão “Agendar visita”
  • Abertura com a lista de materiais usados nas capas
  • O ofício contado em quatro etapas: dobra, costura, colagem e prensagem
  • Galeria de peças recentes em grid, com imagens de tamanhos diferentes
  • Depoimento de cliente e bloco com endereço, horário e contato

O que pratiquei

  • Tema próprio no @theme, com as cores e fontes do briefing
  • Grid de 2, 3 e 4 colunas que se reorganiza com o prefixo md:
  • Galeria montada com grid-cols e grid-rows
  • Bordas, divisórias e cores com transparência
  • Estados de hover nos links e botões

Tecnologias: HTML e Tailwind CSS 4

Sobre

Estudo Engenharia de Software na FIAP e gosto da parte em que um layout estático vira uma página de verdade no navegador.

Antes do código, vim do desenho: fiz arte digital, adesivos e ilustrações sob encomenda, e hoje crio as embalagens da minha própria loja de cookies. Esse olhar para composição e cor é o que levo para o front-end.

Na faculdade aprendi a estruturar páginas com HTML semântico, a montar layouts com Flexbox e Grid e a adaptá-los para telas pequenas. Nas últimas aulas usei o Bootstrap, com componentes prontos, e o Tailwind, com classes utilitárias e tema próprio. O próximo passo é JavaScript, e estou procurando um estágio para aprender com um time.
